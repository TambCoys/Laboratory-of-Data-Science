# 🎧 Laboratory of Data Science — Music Streaming Analytics  
_A Data Engineering & Analytics Project (2025)_

## 👋 About the Project
This repository contains the full end-to-end work I developed for the **Decision Support Systems (Module II)** course at the University of Pisa.  
The project simulates the architecture and analytical workflow of a **real music-streaming company**, from raw data to decision-making dashboards.

The goal was to design and implement a complete **data pipeline**, using industry-relevant technologies such as Python, SSIS, SQL Server, MDX, and PowerBI.

---

## 🧩 Project Overview

### **✔ Data Understanding (Assignment 1)**
- Extensive exploration of **tracks.json** and **artists.xml**  
- Missing-value analysis  
- Enrichment with **external geographic data** (Nominatim geocoding)  
- First insights on lyrics, seasons, genres, and streaming behavior
